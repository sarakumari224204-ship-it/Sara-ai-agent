# Sara AI — Offline Marriage Bureau Agent v2

Package: `com.saraai.offline`

Native Kotlin + Compose + llama.cpp (CPU, ARM64).

## Features
- Real local LLM chat (same pipeline as WhatsApp auto-reply)
- WhatsApp + WhatsApp Business + other messaging apps (dynamic, not camera)
- Knowledge: manual, paste, PDF, TXT, CSV, JSON, DOCX
- Structured marriage profiles
- Owner instructions that affect prompts
- In-app GGUF download (Hugging Face HTTPS) + local import
- Premium Material 3 navigation UI

## Build
GitHub Actions → Android debug APK → artifact `sara-ai-offline-debug-apk`

## Privacy
Customer messages are temporary only. No cloud AI.
